# Game specification

**The full game specification has still not been added to the repository.**

Until it is, implementation follows:

1. the phase briefs given to the developer (Phase 0, Phase 1 and later), and
2. the design direction from [reference-screenshots/](reference-screenshots/README.md).

Every gameplay number lives in `src/shared/Config/`, so values can be brought in line with
the specification without changing code. The assumptions made so far are listed in
[STATUS.md](STATUS.md#design-assumptions-pending-the-specification).

Paste the full specification here, or link to it, and review the assumptions against it.
