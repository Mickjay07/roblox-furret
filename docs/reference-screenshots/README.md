# Reference screenshots

The original reference screenshots live on the developer's machine at:

```
~/Downloads/Ferret frenzy/reference-screenshots/
```

They could not be reached from the cloud development environment during Phase 0, so none
are in the repository yet.

To make them available to future phases (and to cloud sessions), copy them here and
commit them:

```bash
cp ~/Downloads/"Ferret frenzy"/reference-screenshots/* docs/reference-screenshots/
git add docs/reference-screenshots && git commit -m "Add reference screenshots"
```

Use short, descriptive file names (for example `hud-main.png` or `pack-opening.png`), and
note anything that isn't obvious from the image in this README.
